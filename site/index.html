01 / THE WORK

Three tracks.
One obligation to be honest.

PRIVATE HOUSEHOLD APP

Reduce the day.
Not the truth.

Routines, Done, Undo, Snooze, minimum mode, private state and a local supervisor. A cleared reminder cannot silently become a completed real-world obligation.

BOUNDED DELIVERY BRIDGE

Receive a proposal.
Not a command.

An offline reference for strict admission, durable queues, acknowledgements, duplicate handling and recovery. No public listener or production credentials.

SPARK CALIBRATION

Use native tools.
Test their limits.

A reusable reasoning skill and field exercises for Google Workspace. Explicit invocation and meaningful state transitions—not a promise that prompts enforce permissions.

THE CORE DISTINCTION

Observed ≠ accepted.
Scheduled ≠ delivered.
Dismissed ≠ completed.

Each transition needs the right kind of evidence. Ordinary completion can be self-reported. Consequential external actions need their own authority and verification.

03 / BOUNDARIES

Useful autonomy.
Not unlimited trust.

What this demonstrates

State modeling, narrow authority, recovery semantics, reproducible tests, field calibration and evidence-driven architecture changes.

Robert King led the problem framing, iterative design and operator testing. AI assisted code, analysis and documentation.

What it does not claim

No autonomous banking. No clinical or physical-safety qualification. No guaranteed notifications. No globally enforced broker over every connected tool. No independent security certification.

A Pi, MCP service and extra cloud infrastructure remain optional—not prerequisites to reviewing the work.
