# Captured public-source reproduction

This directory records one actual local rerun of the curated publication source.
`SUMMARY.json` identifies the environment, executed commands, results and scope.
The `household/` and `bridge/` files list individual test outcomes. These are
same-author/AI-assisted checks, not an independent security assessment.

Operator-reported native-platform trials are in `../field/calibration.json` and
are not added to the automated test counts. Notification failures remain OPEN.
